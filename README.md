# Virat Kohli Cricket Analytics: Performance Analysis and Predictive Modeling Using Machine Learning

A data science project analyzing Virat Kohli's century-making career across international and IPL cricket. The project combines exploratory data analysis, feature engineering, and machine learning to uncover performance trends and predict Strike Rate — all presented through an interactive Streamlit dashboard.

## 📌 Overview

This project analyzes all 92 centuries scored by Virat Kohli using historical match data. It applies data analysis, visualization, and machine learning techniques to identify performance trends, key batting patterns, and the factors most strongly affecting scoring, while building a predictive model to estimate Strike Rate for a given match scenario.

Key questions explored:
- How has Kohli's strike rate evolved across formats (Test, ODI, T20, T20I) and years?
- Which match factors — format, batting position, team total, match result — correlate most with strike rate?
- Can a machine learning model reliably estimate strike rate using historical patterns?

## 🎯 Objectives

- Clean and explore Virat Kohli's centuries dataset
- Perform exploratory data analysis to uncover format-wise and year-wise trends
- Engineer features relevant to predicting Strike Rate, while avoiding data leakage
- Build and evaluate machine learning models (Random Forest, Ridge Regression) using cross-validation
- Visualize insights and serve live predictions through an interactive Streamlit dashboard

## 📊 Dataset

`Virat_Kohli_100s.csv` contains 92 rows — one for each century Virat Kohli has scored — with the following columns:

| Column | Description |
|---|---|
| Score, Balls, Strike Rate | The innings itself |
| Format | Test, ODI, T20, or T20i |
| Inning, Position | Batting order context |
| Against, Venue, Host Nation, Series, Year | Match context |
| Team Total, Wickets lost | Team performance |
| Win, Not Out, Captain, MOTM | Match/personal outcomes |

## 🚀 Usage

**Train the model:**
```bash
python model.py
```
Loads the dataset, trains a Ridge Regression pipeline, prints MAE/R² and feature coefficients, and saves the trained model to `virat_ridge_model.pkl`.

**Launch the dashboard:**
```bash
streamlit run app.py
```
Make sure `Virat_Kohli_100s.csv` and `Virat.jpg` are in the same folder as `app.py`. The dashboard opens in your browser with filters, trend charts, a Strike Rate prediction tool, and model insights.

## 📈 Key Insights

- **Match format is the single strongest predictor of strike rate.** T20 and T20i innings push strike rate sharply upward, while Test innings pull it sharply downward — a pattern the model learned purely from the data, consistent with real cricketing logic.
- With only 92 rows, a single train-test split can be misleading — 5-fold cross-validation showed average R² scores around 0.49–0.59, with meaningful variance between folds, highlighting the limits of a small dataset.
- The model predicts "typical" innings well (e.g. a steady ODI century) but underestimates exceptional, high-pressure performances (e.g. a match-winning T20 World Cup chase), since features like match pressure or bowling quality aren't captured in the data.

## 🤖 Modeling Approach

- **Problem type:** Regression (predicting Strike Rate)
- **Target variable:** Strike Rate
- **Features used:** Format, Inning, Position, Year, Team Total, Wickets lost, Win, Not Out, Captain, MOTM
- **Features excluded:** Score and Balls (would leak the target), and high-cardinality columns like Against, Venue, Series, Host Nation
- **Models tried:** Random Forest Regressor, Ridge Regression
- **Preprocessing:** One-hot encoding for categorical features, StandardScaler for numeric features, wrapped in a scikit-learn Pipeline + ColumnTransformer
- **Evaluation metrics:** MAE, R² (single split and 5-fold cross-validation)
